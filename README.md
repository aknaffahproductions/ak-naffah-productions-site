# AK Naffah Productions Website

A responsive static website built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — homepage
- `work.html` — searchable/filterable slate
- `about.html` — biography
- `awards.html` — recognition
- `contact.html` — contact details and enquiry form
- one HTML page per project
- `assets/css/styles.css`
- `assets/js/site.js`

## Add your images

Place JPG files in `assets/images/` using the filenames listed in that folder's README.

## Add screenplay PDFs

Place PDF files in `assets/scripts/` using the filenames listed in that folder's README.

## Contact form

The current form uses `mailto:` and opens the visitor's email application.
For a true browser-submitted form, connect Formspree, Netlify Forms or another form backend.

## Publishing

Upload the full folder contents to your web host's public directory. Common directory names are:

- `public_html`
- `www`
- `htdocs`

Make sure `index.html` is in the root public directory.

## Domain

Point `aknaffahproductions.com` to your hosting provider using the DNS records supplied by that provider.

## Important final edits

- Replace the placeholder About biography with your approved biography.
- Verify the awards list.
- Replace the LinkedIn and IMDb search links with your exact profile URLs where available.
- Add a favicon and social sharing image.
- Consider not publishing full screenplay PDFs publicly; a request-access button is safer for unreleased work.
